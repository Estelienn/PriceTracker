PriceTracker

PriceTracker - це веб-сервіс для моніторингу та порівняння цін на товари в популярних супермаркетах. Проєкт розроблено в рамках лабораторної роботи з веб-технологій.

Застосовані технології:

У проєкті використано сучасні підходи до верстки та стилізації:

1. HTML5 
Використано семантичні теги для покращення структури документа та SEO:
 `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`
 Атрибути валідації форм (`required`, `type="email"`)

2. CSS3 (Flexbox & Grid)
Для побудови макету використано комбінацію сучасних технологій:
Flexbox: Використовується для навігаційного меню, вирівнювання елементів у шапці, розміщення карток "Split Layout" (контакти, карта) та центрування контенту.
CSS Grid: Застосовано для створення адаптивних сіток у блоках "Статистика" (`.stats-grid`) та "Переваги" (`.features-list`).

3. Адаптивний дизайн (Responsive Web Design)
Сайт (повинен) коректно відображається на мобільних пристроях, планшетах та десктопах завдяки:
Media Queries (`@media`): Змінюють розташування блоків з горизонтального на вертикальне при ширині екрану менше 900px та 768px.
Гумова верстка: Використання відносних одиниць (`%`, `flex: 1`).

4. Організація стилів (Модульність)
CSS розбито на окремі файли для кращої структуризації та підтримки коду (через `@import`):
"variables.css" -  змінні кольорів, шрифтів та розмірів.
"base.css" - скидання стилів та базові налаштування.
"layout.css" - основний каркас сторінки (header, footer, сітка).
"components.css" - стилі компонентів (кнопки, картки, форми, таблиці).
"main.css" - головний файл-збирач.

5. Додаткові можливості
Валідація форм: Використання псевдокласів `:invalid` та `:valid` для візуального відображення помилок введення (червона/зелена рамка).
CSS Variables: Глобальні змінні (`--color-primary`, `--font-main`) для швидкої зміни теми.
Векторна графіка (SVG): Використання SVG для іконок та кнопок.
